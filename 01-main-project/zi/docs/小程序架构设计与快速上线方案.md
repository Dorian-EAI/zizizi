**真正的发布阻断**在 [`实施状态与上线清单.md`](../docs/实施状态与上线清单.md) 第 5 节，是**部署侧配置与基础设施**，代码无法绕过：

- 后端 `WX_APPID` 未与小程序 AppID 完成生产交叉校验；

## 1. 已实施的架构改动（本次动手）

> 原则：**只动结构与启动逻辑，不碰任何页面视觉内容**，保证页面继续忠于 `zjrnew.design` 画布与 HTML。

### 1.1 `app.json` 增加 `preloadRule`（消除分包白屏）

8 个主包 Tab/入口页触发对应分包预下载（`network: "all"`，覆盖蜂窝网络，适配小区扫码场景）：

```json
"preloadRule": {
  "pages/entry/index":        { "network": "all", "packages": ["package-client"] },
  "pages/client-home/index":  { "network": "all", "packages": ["package-client-order", "package-client-user"] },
  "pages/client-orders/index":{ "network": "all", "packages": ["package-client-order", "package-client-user"] },
  "pages/client-mine/index":  { "network": "all", "packages": ["package-client", "package-client-user"] },
  "pages/worker-home/index":  { "network": "all", "packages": ["package-worker", "package-client-user"] },
  "pages/worker-orders/index":{ "network": "all", "packages": ["package-worker"] },
  "pages/worker-wallet/index":{ "network": "all", "packages": ["package-worker"] },
  "pages/worker-profile/index":{ "network": "all", "packages": ["package-worker", "package-client-user"] }
}
```

用户点进订单详情（`package-client-order`）或切到师傅端时不再现拉分包，弱网下也无明显白屏。团队《微信小程序开发技术规范》2.3 节本就要求配 `preloadRule`，此前 `app.json` 缺失，现已补齐。

### 1.2 删除死代码 `components/custom-tab-bar/`

该目录仅有 `index.wxml` + `index.wxss`，**无 js/json、零页面引用**（真实生效的是 `components/tab-bar`，被 8 个 Tab 页引用）。已删除，主包减 ~16 KB。

### 1.3 字体加载集中到 `utils/font.js`（懒加载，令牌不变）

- `app.js` 顶部对 `assets/fonts/fonts.js`（626 KB base64）的同步 `require` 已移除；
- 字体逻辑抽到 `utils/font.js` 的 `loadFontsOnce()`，`onLaunch` 改为 `require('./utils/font').loadFontsOnce()`；
- **视觉令牌完全照搬**：`Noto Serif SC`(400/700)、`Cormorant Garamond`(700) 的 base64 与 gstatic 网络回退、`Noto Sans CJK SC` 的 UGC 网络字体，全部与改动前一致 → 画布衬线标题外观零变化。

> 本次**保留 base64 内嵌**而非改 CDN：国内微信环境直连 gstatic 不稳，base64 是最可靠的方案，且主包 1.8 MB 仍可提审。集中到 `utils/font.js` 是为后续切 CDN 预留单点。

### 1.4 画布保真抽查（验证「页面忠于设计」）

抽查 `client-mine`：HTML 画布与小程序页面共享同一套设计令牌——`styles/glass-neu.wxss` 等共享样式携带与画布一致的青色 `#0D9488 / #14B8A6` 与 `Noto Serif SC`，由全局 `app.wxss` 引入；页面级 wxss 仅承载子集。`data-dom-id` 在 WXML 为零属正常（那是设计工具的交互标注，运行时用 `bindtap`）。**结论：页面并非脱离画布，而是靠共享样式继承设计令牌。** 不做什么：不盲跑 133 文件重生成（仓库无 design→WXapp 同步工具，会破坏业务逻辑），改为提审前人工逐页视觉验收。

### 1.5 字体 CDN 化兼容骨架（已就绪，待域名即可瘦身）

- `config/env.js` 每个环境新增 `fontCDN` 字段；`getRuntimeConfig()` 返回 `fontCDN`；`app.js` 的 `globalData` 暴露 `fontCDN`。
- `utils/font.js` 改为 **CDN 优先、base64 回退**：检测到 `fontCDN` 非空 → 走网络加载（CDN 失败回退 gstatic，不再回退主包 base64，从而主包可瘦身）；为空（默认）→ 行为与 1.3 完全一致，仍是主包内嵌 626 KB base64。
- **零默认行为变化**：当前所有环境 `fontCDN` 留空，线上表现与改动前逐像素一致；主包体积仍 1.8 MB，不影响提审。
- **瘦身开关已闭合**：提供自有 OSS/COS 域名并上传 3 个衬线 woff2（`noto-serif-sc-400/700.woff2`、`cormorant-garamond-700.woff2`）+ UGC 的 `noto-sans-cjk-sc.woff2` 到该根目录后，只需在 `env.js` 填 `trial/release` 的 `fontCDN`，并删除 `assets/fonts/fonts.js`，主包即降到约 1.1 MB。

## 2. 目标架构（修订）

### 2.1 主包体积与真实余量

| 组成 | 体积 | 处置 |
|---|---:|---|
| `assets/fonts/fonts.js` | ~626 K | 暂留主包（base64 最稳）；**接 CDN 后可移出** |
| `pages/`（18 主包页） | ~700 K | 保留核心双角色主链路 |
| `styles/` + `app.wxss` | ~216 K | 共享样式，保留 |
| 其余 utils/components/api | ~260 K | 保留 |
| **合计主包** | **~1.8 MB** | **< 2 MB 上限，可提审** |

主包当前通过审核，但字体占 37% 压缩了未来迭代余量。**要压到 ≤ 1.0 MB，唯一安全路径是把字体搬上自有 CDN**（后端已有 OSS/COS 能力），届时主包可降到 ~1.1 MB。

### 2.2 字体 CDN 化路径（骨架已就绪，填域名即生效）

> ✅ **已在 1.5 落地**：`font.js` 已支持 CDN 优先加载，代码无需再改。你只需在 `env.js` 的 `trial/release` 填入 `fontCDN`、在「request 合法域名」加入该 CDN，并删除 `assets/fonts/fonts.js`，主包即从 ~1.8 MB 降到 ~1.1 MB。下方为配置示例。

```javascript
// env.js 中填入（无需改 font.js 代码）
trial:  { /* ... */ fontCDN: 'https://cdn.example.com/fonts' },
release: { /* ... */ fontCDN: 'https://cdn.example.com/fonts' }
```

需上传到 CDN 根目录、文件名须与 `font.js` 中 `SERIF_FILES` / `UGC_FILE` 完全一致（结尾无斜杠）：

- `noto-serif-sc-400.woff2`、`noto-serif-sc-700.woff2`（Noto Serif SC，标题/数字衬线）
- `cormorant-garamond-700.woff2`（Cormorant Garamond，拉丁标题）
- `noto-sans-cjk-sc.woff2`（Noto Sans CJK SC，UGC 无衬线，支持 emoji 与生僻字）

WXSS 品牌标题保留系统字体兜底（`font-family: 'Noto Serif SC', -apple-system, 'PingFang SC', sans-serif;`），避免加载期字宽跳变（FOUT）。

### 2.3 双角色 8 Tab 页是否下沉分包（**本次未做，标记可选**）

8 个 Tab 页当前在主包，理论可下沉到 `package-worker` / `package-client`。但：

- 主包 1.8 MB 已通过 2 MB 上限，下沉不是提审必需；
- `client-home` 被 11 处引用，下沉需改全部导航路径，回归成本高、风险大；
- 微信主包 `require` 子包模块会被编译器拉回主包，单纯挪文件并不能减主包体积。

因此**本次不做下沉**，留给有 CDN 后一并优化。若要下沉，必须同步改 `app.json` 注册路径 + 全部 `wx.navigateTo` 绝对路径 + 回归「用户端↔师傅端」切换的页面栈恢复。

## 3. MVP 范围与特性开关

### 3.1 首版页面清单（约 30 页，其余进二期）

**用户端主链路**：`entry → client-login → client-home → client-publish → client-quote-list → client-payment → client-payment-result → client-order-detail → client-order-tracking → client-order-comment → client-order-cancel → client-price-adjust`

**师傅端主链路**：`worker-application → worker-certification → worker-home → worker-quote-submit → worker-orders → worker-wallet → worker-withdraw`

**审核必需页**（缺一项即被拒）：`client-agreement`、`client-privacy`、`client-bind-phone`、`client-customer-service`、`client-feedback`

### 3.2 特性开关架构（二期入口不靠删代码）

二期能力（年卡、积分商城、发票、会员等）**不要改 `app.json`**（改即重新提审），改由服务端下发开关：

```javascript
// 启动时 GET /api/config/features → { points_mall:false, annual_card:false }
// utils/feature.js
const isOn = (key) => {
  const flags = (getApp() && getApp().globalData.featureFlags) || {}
  return flags[key] === true
}
module.exports = { isOn }
```
```xml
<view wx:if="{{showPointsMall}}" class="menu-item" bindtap="goPoints">积分商城</view>
```

> **特性开关不能取代资金安全**：主 PRD「已安全关闭」的能力（年卡、积分兑换、保证金真实支付、主动提现到账）缺真实资金通道，开关只隐藏入口，**服务端仍须返回不可用**，不得仅靠前端隐藏。

## 4. 获客架构（双边市场冷启动）

顺序错了就白烧钱：**没有师傅在线，需求侧补贴全部浪费。**

| 阶段 | 目标 | 微信杠杆 | 北极星 |
|---|---|---|---|
| ① 先备供给 | 种子师傅 | 地推招募、师傅邀请返现、免保证金试跑 | 在岗师傅 ≥ 30 |
| ② 再换首单 | 首批用户 | 小区电梯贴码（带 `scene`）、首单立减、公众号导流 | 日完单 ≥ 20 |
| ③ 靠消息留存 | 提复购 | 订阅消息召回、完单分享卡片、视频号挂载 | 30 日复购 ≥ 25% |

**渠道小程序码**（维修场景 ROI 最高，必须带 `scene` 归因）：

```javascript
// 服务端 wxacode.getUnlimited，scene 最长 32 字符
{ "scene": "c7f2k9", "page": "pages/client-publish/index" }
onLoad(o){ const s=o.scene?decodeURIComponent(o.scene):''; if(s) this.trackChannel(s) }
```

**订阅消息**注意：居家维修通常只能用**一次性订阅**（一次授权只发一条），按订单节点累积授权次数，别指望一次授权吃到底。授权时机放在支付完成后，而非进小程序就弹。

**分享卡片 / 搜索收录**：分享图预生成到 CDN 不用 canvas 现画；检查 `sitemap.json` 开放主链路给微信索引，「上门维修+城市」是自然流量。

## 6. 风险提示

1. **真实阻断在部署侧**：代码已就绪，但 `env.js` 空配置、后端未注入真实密钥/支付/存储会让体验版和正式版都无法联通。这是「快速上线」的头号依赖。
2. **特性开关不取代资金安全**：关闭能力必须服务端返回不可用，前端隐藏不够。
3. **冷启动先备供给**：跳过师傅招募直接投需求侧，用户发单无人报价即首单流失，补贴全废。
4. **画布同步靠人工验收**：仓库无 design→WXapp 自动化同步工具，`DESIGN_SYNC_REPORT` 仅检测「基线后变更」不替代肉眼比对；133 个基线后变更文件需在提审前逐页截图验收，不得为消数字而 `--accept`。
5. **字体 CDN 化会带来一次 FOUT**：若二期切 CDN，品牌标题须配系统字体兜底。

# 画布页面层级排版说明

## 排版逻辑

采用**左对齐树状展开布局**，从上到下、从左到右逐层展开：

- **Row 0（第一行）**：客户端一级入口页面（5个 Tab 页面），水平排列，子树之间空一列
- **Row 1（第二行）**：每个一级页面能直接打开的二级页面，从对应父页面正下方的列开始依次排列
- **Row 2（第三行）**：每个二级页面能直接打开的三级页面，从对应父页面正下方的列开始依次排列
- **Row 3（第四行）**：以此类推，每一级页面的下一级页面放在该页面的下一行、正下方开始
- 不同父页面的子页面组之间**空一列**作为分隔
- 同一行所有页面**顶部对齐**
- 子页面的第一列与父页面**垂直对齐**（左对齐树状）
- 师傅端页面紧接客户端最后一行之后，**隔一行**开始

## 页面尺寸与间距

- 页面宽度：375px
- 页面高度：812px
- 列间距（水平）：80px
- 行间距（垂直）：120px
- 起始坐标：x=100, y=100

## 坐标计算规则

```
pageW = 375    // 页面宽度
pageH = 812    // 页面高度
gapX  = 80     // 列间距
gapY  = 120    // 行间距
startX = 100   // 起始 X
startY = 100   // 起始 Y

第 col 列的 x = startX + col * (pageW + gapX)
第 row 行的 y = startY + row * (pageH + gapY)
```

## 2. 分包加载规范

### 2.1 大小限制
- **主包**：≤ 2MB（启动时加载）
- **分包**：每个 ≤ 2MB
- **总大小**：≤ 20MB

### 2.2 分包配置
```json
{
  "pages": [
    "pages/home/index",
    "pages/order/index"
  ],
  "subpackages": [
    {
      "root": "package-user",
      "name": "user",
      "pages": [
        "pages/profile/index",
        "pages/settings/index"
      ],
      "independent": false
    },
    {
      "root": "package-order",
      "pages": [
        "pages/detail/index"
      ]
    }
  ],
  "preloadRule": {
    "pages/home/index": {
      "network": "all",
      "packages": ["package-user"]
    }
  }
}
```

### 2.3 分包原则
- **主包**：TabBar 页面、首页、登录页等高频访问页面
- **分包**：低频功能页、详情页、设置页等
- **预加载**：在当前页配置 `preloadRule` 预加载下一分包

### 2.4 分包路径
```javascript
// 跳转到分包页面
wx.navigateTo({
  url: '/package-user/pages/profile/index'
})

// 跳回主包
wx.switchTab({
  url: '/pages/home/index'
})
```

## 3. 代码规范

### 3.1 JavaScript 规范

```javascript
// ✅ 推荐：使用 const/let
const apiUrl = 'https://api.example.com'
let isLoading = false

// ✅ 推荐：箭头函数
const handleTap = () => {
  this.setData({ active: true })
}

// ✅ 推荐：模板字符串
const message = `订单 ${orderId} 已创建`

// ✅ 推荐：解构赋值
const { name, phone } = this.data.userInfo

// ✅ 推荐：默认参数
function formatDate(date = new Date()) {
  return date.toLocaleDateString()
}
```

### 3.2 禁止的语法

```javascript
// ❌ 禁止：可选链（?.）
const name = user?.name  // 小程序不支持

// ✅ 正确写法
const name = user && user.name

// ❌ 禁止：空值合并（??）
const value = input ?? 'default'

// ✅ 正确写法
const value = input !== undefined && input !== null ? input : 'default'

// ❌ 禁止：ES2020+ 语法
const list = [1, 2, 3]
const result = list.at(-1)  // 不支持
```

### 3.3 数据绑定规范

```javascript
// ✅ 推荐：setData 仅传需要更新的字段
this.setData({
  'userInfo.name': '张三',
  'userInfo.phone': '13800138000'
})

// ❌ 避免：大量数据一次更新
this.setData({
  ...veryLargeObject  // 影响性能
})

// ✅ 推荐：使用数据路径更新
this.setData({
  'list[0].status': 'active',
  'list[0].count': 10
})
```

### 3.4 生命周期规范

```javascript
Page({
  data: {
    list: [],
    loading: false
  },

  // ✅ 推荐：数据初始化放在 onLoad
  onLoad(options) {
    this.initPage(options.id)
  },

  // ✅ 推荐：刷新数据放在 onShow
  onShow() {
    this.refreshData()
  },

  // ✅ 推荐：清理资源放在 onUnload
  onUnload() {
    this.clearTimer()
    this.unsubscribeEvent()
  },

  methods: {
    async initPage(id) {
      this.setData({ loading: true })
      try {
        const data = await this.fetchData(id)
        this.setData({ list: data })
      } finally {
        this.setData({ loading: false })
      }
    }
  }
})
```

## 8. 安全规范

### 8.1 域名配置

```json
// app.json 或 微信公众平台配置
{
  "networkTimeout": {
    "request": 10000,
    "downloadFile": 10000,
    "uploadFile": 10000,
    "connectSocket": 10000
  }
}
```

| 类型 | 配置 | 说明 |
|------|------|------|
| request | request 合法域名 | HTTPS 接口 |
| uploadFile | uploadFile 合法域名 | 上传接口 |
| downloadFile | downloadFile 合法域名 | 下载接口 |
| socket | socket 合法域名 | WebSocket |

### 8.2 数据安全

```javascript
// ✅ 推荐：敏感信息加密存储
const SECRET_KEY = 'your-secret-key'

// 存储
wx.setStorageSync('token', encrypt(userToken, SECRET_KEY))

// 读取
const token = decrypt(wx.getStorageSync('token'), SECRET_KEY)

// ✅ 推荐：不在本地存储敏感信息
// ❌ 避免
wx.setStorageSync('password', password)

// ✅ 推荐：使用会话管理
wx.setStorageSync('session_id', sessionId)
```

### 8.3 请求安全

```javascript
// ✅ 推荐：请求拦截器
const request = (options) => {
  return new Promise((resolve, reject) => {
    wx.request({
      url: BASE_URL + options.url,
      method: options.method || 'GET',
      data: options.data,
      header: {
        'Authorization': `Bearer ${token}`,
        'Content-Type': 'application/json',
        'X-Request-ID': generateRequestId()
      },
      success: (res) => {
        if (res.statusCode === 401) {
          wx.reLaunch({ url: '/pages/login/index' })
          reject(new Error('未授权'))
          return
        }
        resolve(res.data)
      },
      fail: reject
    })
  })
}
```

## 9. 状态管理规范

### 9.1 全局状态

```javascript
// utils/store.js
const store = {
  state: {
    userInfo: null,
    settings: {}
  },

  set(key, value) {
    this.state[key] = value
    this.notify(key)
  },

  get(key) {
    return this.state[key]
  },

  listeners: {},

  subscribe(key, callback) {
    if (!this.listeners[key]) {
      this.listeners[key] = []
    }
    this.listeners[key].push(callback)
  },

  notify(key) {
    const callbacks = this.listeners[key] || []
    callbacks.forEach(fn => fn(this.state[key]))
  }
}

module.exports = store
```

### 9.2 数据缓存

```javascript
// ✅ 推荐：分层缓存策略
const cache = {
  // L1：内存缓存（当前会话）
  memory: new Map(),

  // L2：本地存储（持久化）
  async get(key) {
    // 优先读内存
    if (this.memory.has(key)) {
      return this.memory.get(key)
    }

    // 读本地存储
    const cached = wx.getStorageSync(key)
    if (cached && Date.now() - cached.time < 3600000) {
      this.memory.set(key, cached.data)
      return cached.data
    }

    return null
  },

  async set(key, data, ttl = 3600) {
    this.memory.set(key, data)
    wx.setStorageSync(key, { data, time: Date.now(), ttl })
  }
}
```

## 12. 发布规范

### 12.1 版本号规则
```
主版本号.次版本号.修订号
例：1.0.0, 1.1.0, 1.1.1
```

| 版本 | 说明 | 示例 |
|------|------|------|
| 主版本号 | 功能架构变化 | 1.0.0 |
| 次版本号 | 功能新增 | 1.1.0 |
| 修订号 | Bug 修复 | 1.1.1 |

### 12.2 发布流程
1. **开发版**：本地调试
2. **体验版**：测试人员使用
3. **开发版管理**：上传代码到微信后台
4. **提交审核**：微信审核（1-7 天）
5. **发布上线**：审核通过后发布

### 12.3 审核注意事项
- ✅ 确保所有页面可访问，无空白页
- ✅ 确保无敏感词、无违规内容
- ✅ 确保用户协议、隐私政策完整
- ✅ 确保支付功能合规
- ✅ 确保数据收集有明确说明
